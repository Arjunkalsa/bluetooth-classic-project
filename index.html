How to connect

  1. Use desktop Google Chrome 117 or later.
  2. Pair your Bluetooth serial device in Windows Bluetooth settings.
  3. For Android, the phone needs an app that listens on SPP/RFCOMM; pair the phone to this computer.
  4. Click Connect Bluetooth device and choose it in Chrome.
  5. Send a line. The other side must use newline-delimited text.
Important limit: This page connects to Bluetooth serial (SPP/RFCOMM). It cannot pair with or control arbitrary phones, headphones, keyboards, or car audio. The device must provide a compatible serial service.

Serve from localhost or HTTPS. A file preview or mobile browser may not expose Web Serial.

02 · How the code works

From click to Bluetooth data

Web Serial grants access to the selected port. JavaScript opens it, decodes bytes and writes text.

Choose a device

requestPort() opens Chrome's chooser, filtered to SPP.

Open the link

port.open() opens the RFCOMM serial stream.

Read bytes

A reader decodes UTF-8 and displays complete lines.

Write text

A writer encodes the message and appends newline.

OS pairing

Windows handles radio pairing and link security.

Device protocol

The other device must agree on SPP and message format.

04 · Code explanation

The connection code

The browser picker only opens after the user presses the connect button. 

            
              // Bluetooth Serial Port Profile service UUID
const SPP_UUID = "00001101-0000-1000-8000-00805f9b34fb";

// The user gesture opens the browser device chooser
const port = await navigator.serial.requestPort({
  filters: [{ bluetoothServiceClassId: SPP_UUID }]
});

// Open the RFCOMM serial data stream
await port.open({ baudRate: 9600 });

// Send a UTF-8 line to the device
const writer = port.writable.getWriter();
await writer.write(new TextEncoder().encode("Hello\\n"));
writer.releaseLock();

The operating system and browser handle the radio and pairing. The website handles the selected serial port and the bytes sent through it.

Project boundary

What this website can and cannot do

Can connect

Paired Classic devices exposing SPP/RFCOMM: serial adapters, compatible printers, and devices running an SPP server.

Cannot connect generically

Bluetooth audio, hands-free calls, generic HID keyboards, or phones without a serial service.

Requirements

Desktop Chrome 117+, user permission, device pairing, and a secure origin such as localhost or HTTPS.
